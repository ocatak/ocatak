## Research Profile

My research is in **cyber security**. I work on how digital systems are attacked, and on methods that keep them secure, private and dependable. The work runs from offensive security and malware analysis to cryptographic techniques for computing on encrypted data. It also covers the security of AI systems themselves, and the use of quantum technologies to build the next generation of secure systems. Applications include secure communication networks (5G/6G) and critical infrastructure.

## Research Areas

**Cyber Security**

| Area | Focus |
|---|---|
| **Penetration testing and malware analysis** | Offensive security and vulnerability assessment, malware detection and classification with machine learning, malware datasets |
| **Homomorphic encryption** | Privacy-preserving computation on encrypted data, encrypted machine learning, secure federated learning |
| **Trustworthy AI** | Adversarial machine learning, robustness, uncertainty quantification, security of AI and LLM-based systems |
| **Quantum technologies for security** | Quantum machine learning for security, post-quantum cryptography and crypto-agility, quantum learning theory, quantum-secure communication |

## Research Software

**[QuantumUQ](https://github.com/ocatak/QuantumUQ)** — Uncertainty quantification for quantum machine learning models, with Qiskit and PennyLane backends. Listed in the IBM Qiskit ecosystem.
[Documentation](https://quantumuq.readthedocs.io/) · [PyPI](https://pypi.org/project/quantumuq/)

**[quantum-learning-copy-cost](https://github.com/ocatak/quantum-learning-copy-cost)** — Code accompanying *The Copy Cost of Incompatibility: Minimax Bounds for Supervised Quantum Learning with Single-Copy Measurements*.

**[trustworthyai](https://github.com/ocatak/trustworthyai)** — Implementations and worked examples accompanying the book *Trustworthy AI*.

**[6g_security](https://github.com/ocatak/6g_security)** — Experiments on adversarial robustness and trustworthy learning for 6G communication systems.

**[malware_api_class](https://github.com/ocatak/malware_api_class)** — Mal-API-2019, a public dataset of Windows PE API call sequences for machine-learning-based malware classification.
