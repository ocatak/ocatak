## 🚀 About Me

My research focuses on designing **secure, reliable, and privacy-preserving AI systems** for next-generation communication networks and critical infrastructures.

I work at the intersection of:

- 🔐 AI Security & Adversarial Machine Learning
- 📊 Uncertainty Quantification & Trustworthy AI
- ⚛️ Quantum Machine Learning
- 📡 Secure 5G/6G Communication Systems
- 🔒 Privacy-Preserving ML & Federated Learning
